# Project Name

Đây là bộ khung cấu trúc thư mục tiêu chuẩn.

## Cấu trúc
- `src/`: Mã nguồn chính của ứng dụng
- `tests/`: Chứa các file kiểm thử (Unit test)
- `data/`: Chứa các file dữ liệu tĩnh (đã được ignore không push lên Git)
- `docs/`: Chứa tài liệu thiết kế (Sơ đồ ERD, UML, Draw.io, Visual Paradigm)

## Cài đặt
1. Copy file `.env.example` thành `.env` và điền thông số.
2. Cài đặt các thư viện từ `requirements.txt`.
